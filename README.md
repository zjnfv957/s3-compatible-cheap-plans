# 便宜对象存储：每月10元起的S3兼容方案，图床、备份和网盘该怎么挑套餐

搜"便宜对象存储"的人，需求其实高度一致：给博客当图床、给服务器做备份、给自己搭个能存点东西的网盘。共同点是数据量不大、预算有限，但不想踩"注册送三个月、账单失控"的坑。

判断贵不贵，从来不是看每 GB 单价那一个数字。请求费、外网流出费、跨区费、最小计费周期，随便哪一项都能把账面价格翻倍。所以先把计费模型说清楚，再看雨云对象存储（ROS）这套按月套餐的方案到底划不划算。

## 先搞明白钱花在哪里

雨云对象存储的计费项只有两个：**存储空间**和**流量**，使用前需要先买套餐，套餐按月扣费。没有单列的请求费、操作类型费之类的小字条款。

流量这块有个容易看晕的地方。官方文档写的是"不计算下行流量，只计算上行流量"，而他们定义的"上行"是雨云把文件发给你——也就是**别人下载才扣流量，你上传不扣**。同一个文件被上传十次，账上一分不扣。

> 官方计费示例：用户上传文件不扣流量；从对象存储下载 1GB 扣 1GB 流量，套餐内有余额就优先扣套餐；同区域云服务器用内网地址访问同区域对象存储，上下行都不计流量。

对图床、附件这类"写一次、读很多次"的场景，这个规则比单价更有意义。真正的成本大头是下行，而阿里云 OSS、腾讯云 COS 恰恰是在下行上收费最狠的一块。

## 雨云对象存储能做什么

ROS（Rain Object Storage）是雨云的对象存储产品，接口兼容 S3 协议。这一条的实际意义是：PicGo、WordPress 的 S3 插件、Halo、NextCloud、AList、rclone 这些工具基本不用改变用法，填上 Access Key、Secret Key 和 Endpoint 就能连上。

其他几个和成本直接相关的点：

- 内置简易文件管理面板，改个文件、删个桶不用装第三方工具
- 自带默认访问域名，不绑域名也能直接用；要绑自己的域名则需要域名已备案
- 支持防盗链和防火墙，图床被外部站点直接引用时能拦
- 不同存储桶可以设置不同密钥，管理员用实例密钥统一管
- 目前有浙江宁波、湖北十堰两个地区，套餐类型和地区是绑定的

## 和大厂横向比一下

拿"100GB 存储 + 100GB 外网流量"这个基准来比，因为这是个人博客最常见的量级。第三方在 2025 年 12 月整理过各家资源包的价格：

差距主要不在存储，在流量。阿里云 OSS 按量计费的标准存储是 0.12 元/GB/月，外网流出则是闲时 0.25 元/GB、忙时 0.50 元/GB——存储费看着便宜，账单往往是被流量抬起来的。

这个对比有两个前提要说清楚：一是大厂普遍还有 HTTPS 请求费、图片处理费、跨区流量费等项目，上表只加了存储和流量两笔；二是各家资源包价格和促销会变，下单前请以官网当前页面为准。雨云这边的优势是结构简单，缺点是能对比的维度也就这两种，没有丰富的存储层级可选。

## 三种套餐对应三种用法

**流量优先（宁波）**——存储小、流量大。典型的图床、博客附件场景：图片总量可能就几个 GB，但每天被人访问。10GB 存储 + 50GB 流量 10 元/月这一档，多数个人博客用不完。

**存储优先（十堰）**——存储大、流量小。适合备份和归档：网站定期打包上传、手机相册同步、数据库冷备。4TB + 1TB 流量 399 元/月，折合存储 0.1 元/GB 左右，比按量买存储划算得多。这类数据一年下载不了几次，流量给得少不是问题。

**平衡（十堰）**——两者按 1:1 配。给别人的网盘分享文件、小型团队的素材库、需要转码后分发的视频项目，都属于"既要存又要经常读"的类型。1TB+1TB 的 198 元档是这一类的分界线。

一个实用建议：如果拿不准，先买最小档，观察一个月的实际用量再升级。雨云的套餐支持升级，超量也能开弹性计费顶着，没必要为了"怕不够"一次性买大。

## 便宜之外，有三件事得先想清楚

**只有两个可用地区。**浙江宁波和湖北十堰，都在国内。如果你的访客主要在海外，节点覆盖会直接反映到加载速度上，这类需求应该把 Cloudflare R2 一类不按流量收费的海外方案放进备选。

**用超默认停服，是把双刃剑。**好处是不会产生意外账单，代价是量到顶了服务会中断，需要你自己留意控制台的用量。把弹性计费开着的人，配合防盗链一起用会更稳妥。

**长期稳定性资料不多。**目前网上关于 ROS 的内容，绝大多数是 PicGo、WordPress、Halo、NextCloud、AList 的接入教程，属于"能跑起来"层面的验证；至于连续跑一年两年的稳定性表现，公开可查的长期测评很少。价格有优势这点没什么争议，稳定性只能靠自己的实际使用去判断，重要数据记得在别处再留一份。

## 从注册到能用，大概这几步

1. 注册账号并完成实名认证
2. 在积分商城兑换免费额度，或直接选购上面表格里的套餐
3. 进对象存储控制台，创建一个存储桶，桶名被别人占用时换一个
4. 需要对外访问就开启公共访问，必要时配置防盗链
5. 在存储桶的"信息与监控"里拿到 Access Key、Secret Key 和 API 端点
6. 把这些信息填进 PicGo、WordPress 的 S3 插件、rclone 或 NextCloud，官方文档里有 NextCloud 的完整图文流程

整个流程不用绑域名、不用备案也能先跑通，这也是它适合拿来试水的原因。

## 常见问题

**上传文件要花钱吗？**
不计。只有从存储桶下载文件才扣流量，你上传的数据不产生流量费用。

**支持 S3 接口吗？**
支持。用 AWS CLI、boto3 或任何 S3 兼容客户端都能操作，官方文档里也有 boto3 的示例。

**会被盗刷流量吗？**
可以先把弹性计费关掉，写到套餐上限就自动停止访问；再配合防盗链，能挡掉一部分外部站点的直接引用。完全杜绝不现实，但失控的代价可控。

**能绑定自己的域名吗？**
可以，不过域名需要已完成备案。

**最低多少钱能开始？**
湖北十堰 100GB 存储 + 25GB 流量一档 13 元/月，宁波 10GB 存储 + 50GB 流量一档 10 元/月，是目前表里最便宜的两档。想更保险，先用论坛教程里的免费额度试一个月，觉得合适再切付费套餐——毕竟便宜的对象存储不止一家，能长期用下去的那家才算选对了，👉 [去雨云看看当前套餐和可用额度](https://www.rainyun.com/MzA2MTc2_)。
